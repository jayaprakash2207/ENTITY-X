## 🎯 What is Entity X?

<img align="right" src="https://capsule-render.vercel.app/api?type=cylinder&color=0:6366f1,100:8b5cf6&height=120&section=header&text=AI%20Forensics&fontSize=30&fontColor=ffffff&animation=blinking" width="220"/>

**Entity X** is a **desktop-native AI forensic platform** that acts as your personal digital truth defender. It silently monitors every image, article and video you encounter online — analyzing them for manipulation, synthetic generation, and misinformation **in real time**.

> 🛡️ **Install once. No API keys. No setup. Full AI — out of the box.**

The app embeds a live browser with an AI monitoring layer. As you browse, Entity X automatically:

- 🔬 Scans images using a **5-model ML ensemble** (ViT 99.3% + SwinV2 98.1% + CVPR-2023 research model)
- 🤖 Detects AI-generated text using **RoBERTa transformer classifiers**
- 📰 Performs **forensic article analysis** via Gemini 2.0 Flash
- ⚖️ Provides **legal guidance & complaint drafting** for digital rights
- 📊 Maintains a live **Trust Score** reflecting your session's digital integrity

<br/>

### 🛠️ Run from Source (Developers)

```bash
# Clone
git clone https://github.com/jayaprakash2207/ENTITY-X.git
cd ENTITY-X

# Install Node dependencies
npm install

# Set up Python venv
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r backend/requirements.txt

# Configure your own API keys (optional)
cp .env.example .env

# Launch
npm start
```

## 🔒 Security

<div align="center">

| Security Layer | Implementation |
|---|---|
| 🔐 Electron Hardening | Context isolation · Sandbox · Permission handler · Certificate verify |
| 🌐 SSRF Protection | Blocks all private IP ranges (10.x · 192.168.x · 127.x · 172.16.x) |
| 🔍 Content Validation | MIME type + magic-byte verification on every image |
| 📏 Size Limits | 10 MB hard cap on all downloads |
| 🚫 No Hard-coded Secrets | All keys via environment variables only |
| ⏱️ Rate Limiting | slowapi on all backend API endpoints |
| 🪟 Window Isolation | `setWindowOpenHandler` blocks popups · `will-navigate` guard |

</div>

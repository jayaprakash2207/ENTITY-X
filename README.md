<img src="https://capsule-render.vercel.app/api?type=rounded&color=0:7f1d1d,100:991b1b&height=55&text=🛡️%20Trust%20Score%20System&fontSize=24&fontColor=ffffff&animation=fadeIn" width="65%"/>

<div align="center">

Every browsing session starts at **100 / 100**. Each suspicious detection deducts points:

```
  trust_score  -=  fake_probability  ×  8.0        (clamped 0.0 – 100.0)
```

A full session of HIGH-risk content reaches 0 after ~15–20 detections — giving a meaningful
degradation curve that reflects a real browsing session rather than instant drain.

<br/>

| Score Range | Visual | Meaning |
|:-----------:|:------:|:--------|
| **90 – 100** | 🟢🟢🟢🟢🟢 | ✅ High integrity · minimal suspicious content |
| **70 – 89** | 🟡🟡🟡🟡⚪ | ⚠️ Moderate · some flagged detections |
| **50 – 69** | 🟠🟠🟠⚪⚪ | 🔶 Caution · multiple deepfakes encountered |
| **0 – 49** | 🔴🔴⚪⚪⚪ | 🚨 Critical · heavy misinfo / deepfake zone |

<br/>

> Trust scores are **persisted to SQLite** and recovered across restarts. Each entity's score is
> stored in `trust_history` and joined on query — so Investigation and Forensic Lab always show accurate values.

<div align="center">

| 🔐 Layer | Implementation |
|:--------:|:--------------|
| **Electron Hardening** | `contextIsolation` · `sandbox: true` · `nodeIntegration: false` · `setPermissionRequestHandler` |
| **SSRF Protection** | Blocks all private IP ranges: `10.x` · `192.168.x` · `127.x` · `172.16–31.x` |
| **Content Validation** | MIME type + magic-byte verification on every image before analysis |
| **Image Cache Eviction** | 150 MB cap · 40-item LRU — prevents memory exhaustion attacks |
| **Size Limits** | 10 MB hard cap on all downloads and uploads |
| **No Hardcoded Secrets** | All API keys via `.env` — never committed to source code |
| **Rate Limiting** | `slowapi` on every FastAPI endpoint (30/min image, 10/min video) |
| **Window Guard** | `setWindowOpenHandler` blocks popups · `will-navigate` protection |
| **Queue Guards** | `_imageQueueRunning` · `_videoQueueRunning` · `_audioQueueRunning` prevent race conditions |
| **DB Write Lock** | `threading.Lock()` serializes all SQLite writes — no `check_same_thread=False` |

### Option 2 — Run from Source *(For Developers)*

**Prerequisites:** Node.js 20+, Python 3.11+, Git

```bash
# 1. Clone
git clone https://github.com/jayaprakash2207/ENTITY-X.git
cd ENTITY-X

# 2. Install Node dependencies
npm install

# 3. Install Python dependencies
python -m pip install -r backend/requirements.txt

# 4. Configure environment
cp .env.example .env
# Edit .env and add:
#   GEMINI_API_KEY=...      (https://aistudio.google.com/app/apikey)
#   GROQ_API_KEY=...        (https://console.groq.com/keys)
#   OPENROUTER_API_KEY=...  (https://openrouter.ai/keys)
```

**Start the app (two terminals):**

```bash
# Terminal 1 — Backend
cd backend
python -m uvicorn main:app --reload --port 8000

# Terminal 2 — Electron
node electron-launch.cjs
```

**Run tests:**

```bash
python -m pytest backend/tests/ -q
```

**Build Windows installer:**

```bash
npm run dist
# Output: release/Entity-X-Setup-x.x.x.exe
```

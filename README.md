### 🖼️ Image Deepfake Detection — 5-Model Ensemble

| Rank | Model | Accuracy | Method |
|:----:|-------|:--------:|--------|
| 🥇 | ViT · `dima806/deepfake_vs_real_image_detection` | **99.3%** | HuggingFace GPU |
| 🥈 | SwinV2 · `haywoodsloan/ai-image-detector-deploy` | **98.1%** | HuggingFace GPU |
| 🔬 | UniversalFakeDetect · CLIP ViT-L/14 *(CVPR 2023)* | Research SOTA | HuggingFace GPU |
| 🔍 | CLIP · `umm-maybe/AI-image-detector` | — | HuggingFace GPU |
| 🎨 | SDXL · `Organika/sdxl-detector` | — | HuggingFace GPU |
| 🏷️ | C2PA · EXIF · PNG watermark scanner | **100%** when present | Built-in (Pillow) |

> **Whistleblower Rule** — If any single model scores ≥ 85% AI confidence, the final score is floored to that level. No detector can be silenced by the others.

<div align="center">
<img src="https://capsule-render.vercel.app/api?type=rounded&color=0:7f1d1d,100:991b1b&height=60&section=header&text=🛡️%20Trust%20Score%20System&fontSize=28&fontColor=ffffff&animation=fadeIn" width="70%"/>

<div align="center">

Every session starts at **100 / 100**. Degrades with each suspicious detection:

```
  trust_score  -=  fake_probability  ×  100        (clamped 0 – 100)
```

<br/>

| Score | Indicator | Status |
|:-----:|:---------:|--------|
| **90 – 100** | 🟢🟢🟢🟢🟢 | High integrity · minimal suspicious content |
| **70 – 89** | 🟡🟡🟡🟡⚪ | Moderate · some flagged detections |
| **50 – 69** | 🟠🟠🟠⚪⚪ | Caution · multiple deepfakes encountered |
| **0 – 49** | 🔴🔴⚪⚪⚪ | Critical · heavy misinfo / deepfake zone |

</div>

<div align="center">

| 🔐 Layer | Implementation |
|----------|---------------|
| **Electron Hardening** | Context isolation · Sandbox · `setPermissionRequestHandler` · `setCertificateVerifyProc` |
| **SSRF Protection** | Blocks private IPs: `10.x` · `192.168.x` · `127.x` · `172.16.x` |
| **Content Validation** | MIME type + magic-byte verification on every image |
| **Size Limits** | 10 MB hard cap on all downloads |
| **No Hard-coded Keys** | All secrets via env variables · Never in source code |
| **Rate Limiting** | `slowapi` on all backend API endpoints |
| **Window Guard** | `setWindowOpenHandler` blocks popups · `will-navigate` protection |
